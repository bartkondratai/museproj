System Info

What's actually running this deployment — real accounts with real credentials, cross-checked against the vault. Not the template's full feature list.

How it fits together: GitHub holds the source and runs the deploy on every push to main. The browser calls beartandmusic.pl for the public site; internal-only paths redirect to in.beartandmusic.pl, which Cloudflare Access gates behind Google sign-in, restricted to a single allowed account. Everything server-side goes through Supabase — the database, auth provider, file store, and edge function host. Those functions call out to Resend for email and OpenRouter for AI-assisted features.
